# Интернет-магазин «Web-Larёk»
«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

### Архитектура приложения

Приложение построено с использованием архитектурного паттерна MVP
(Model — View — Presenter).

**Model** отвечает за хранение и обработку данных приложения.
К моделям относятся `Products`, `Basket` и `Buyer`.

**View** отвечает за отображение данных и взаимодействие пользователя
с интерфейсом. Для создания элементов интерфейса используются компоненты,
унаследованные от базового класса `Component`.

**Presenter** отвечает за координацию взаимодействия между моделями,
представлениями и API. Он обрабатывает действия пользователя, получает
данные из моделей, обновляет представление и инициирует запросы к серверу.

Для обмена событиями между частями приложения используется класс
`EventEmitter`, реализующий паттерн «Наблюдатель».

### Базовый код

#### Класс Component
Является базовым классом для всех компонентов интерфейса.
Класс является дженериком и принимает в переменной `T` тип данных, которые могут быть переданы в метод `render` для отображения.

Конструктор:  
`constructor(container: HTMLElement)` - принимает ссылку на DOM элемент за отображение, которого он отвечает.

Поля класса:  
`container: HTMLElement` - поле для хранения корневого DOM элемента компонента.

Методы класса:  
`render(data?: Partial<T>): HTMLElement` - Главный метод класса. Он принимает данные, которые необходимо отобразить в интерфейсе, записывает эти данные в поля класса и возвращает ссылку на DOM-элемент. Предполагается, что в классах, которые будут наследоваться от `Component` будут реализованы сеттеры для полей с данными, которые будут вызываться в момент вызова `render` и записывать данные в необходимые DOM элементы.  
`setImage(element: HTMLImageElement, src: string, alt?: string): void` - утилитарный метод для модификации DOM-элементов `<img>`


#### Класс Api
Содержит в себе базовую логику отправки запросов.

Конструктор:  
`constructor(baseUrl: string, options: RequestInit = {})` - В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

Поля класса:  
`baseUrl: string` - базовый адрес сервера  
`options: RequestInit` - объект с заголовками, которые будут использованы для запросов.

Методы:  
`get(uri: string): Promise<object>` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер  
`post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object>` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется `POST` запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.  
`handleResponse(response: Response): Promise<object>` - защищенный метод проверяющий ответ сервера на корректность и возвращающий объект с данными полученный от сервера или отклоненный промис, в случае некорректных данных.

#### Класс EventEmitter
Брокер событий реализует паттерн "Наблюдатель", позволяющий отправлять события и подписываться на события, происходящие в системе. Класс используется для связи слоя данных и представления.

Конструктор класса не принимает параметров.

Поля класса:  
`_events: Map<string | RegExp, Set<Function>>)` -  хранит коллекцию подписок на события. Ключи коллекции - названия событий или регулярное выражение, значения - коллекция функций обработчиков, которые будут вызваны при срабатывании события.

Методы класса:  
`on<T extends object>(event: EventName, callback: (data: T) => void): void` - подписка на событие, принимает название события и функцию обработчик.  
`emit<T extends object>(event: string, data?: T): void` - инициализация события. При вызове события в метод передается название события и объект с данными, который будет использован как аргумент для вызова обработчика.  
`trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void` - возвращает функцию, при вызове которой инициализируется требуемое в параметрах событие с передачей в него данных из второго параметра.

## Данные и модели данных

### Раздел «Данные»

В приложении используются две основные сущности, которые описывают данные магазина: товар и покупатель.

#### Интерфейс товара IProduct
Описывает структуру данных отдельного товара, представленного в каталоге.
```typescript
interface IProduct {
  id: string;          // Уникальный идентификатор товара
  description: string; // описание товара
  image: string;       // Ссылка на изображение товара
  title: string;       // Название товара
  category: string;    // Категория товара 
  price: number | null;// Цена товара
}
```

#### Тип оплаты TPayment
TPayment описывает доступные способы оплаты:
```typescript
export type TPayment = 'card' | 'cash'; // Карта|Наличные
```

##### Интерфейс покупателя (IBuyer)
IBuyer описывает данные, которые покупатель указывает при оформлении заказа.
```typescript
interface IBuyer {
  payment: TPayment | null;   // Выбранный способ оплаты. Значение null означает, что способ оплаты ещё не выбран
  email: string;       // Электронная почта покупателя
  phone: string;       // Номер телефона покупателя
  address: string;     // Адрес доставки
}

```

### Раздел «Модели данных»

Модели данных отвечают только за хранение и обработку данных приложения. Они не зависят от классов отображения и не работают напрямую с DOM.

В проекте используются три модели данных:

`Products` — каталог товаров;
`Basket` — корзина покупателя;
`Buyer` — данные покупателя.


#### 1. Класс Products
Класс Products отвечает за хранение каталога товаров и выбранного товара для подробного просмотра.

### Конструктор  
`constructor()`  — Конструктор не принимает параметров.


### Поля класса

`protected items: IProduct[]` - Массив всех товаров каталога.
`protected selectedItem: IProduct | null` — товар, выбранный для подробного отображения. Если товар не выбран, значение равно `null`.


### Методы класса 

`setItems(items: IProduct[]): void` - Сохраняет переданный массив товаров в модели каталога.
`getItems(): IProduct[]` - Возвращает массив товаров каталога.
`getItem(id: string): IProduct | undefined` - Находит товар по его идентификатору и возвращает найденный товар. Если товар не найден, возвращается undefined.
`setSelectedItem(item: IProduct): void` - Сохраняет товар, выбранный для подробного отображения.
`getSelectedItem(): IProduct | null` - Возвращает товар, выбранный для подробного отображения. Если товар не выбран, возвращается null.

#### 2. Класс Basket
Класс Basket отвечает за хранение товаров, выбранных покупателем для покупки.

# Конструктор  
`constructor()`  — Конструктор не принимает параметров.

## Поля класса  
`protected items: IProduct[]` - Массив товаров, добавленных покупателем в корзину.  
 

### Методы класса  
`add(item: IProduct): void` - Добавляет переданный товар в корзину.
`remove(id: string): void` - Удаляет товар из корзины по его идентификатору.
`clear(): void` - Полностью очищает корзину.
`getTotalPrice(): number` - Возвращает общую стоимость всех товаров, находящихся в корзине.
`getItems(): IProduct[]` - Возвращает массив товаров, находящихся в корзине.
`contains(id: string): boolean` - Проверяет наличие товара в корзине по его идентификатору. Возвращает true, если товар находится в корзине, и false, если товара нет.
`getCount(): number` - Возвращает количество товаров в корзине.


#### 3. Класс Buyer
Класс Buyer отвечает за хранение и обработку данных покупателя, необходимых для оформления заказа.

# Конструктор  
`constructor()`  — Конструктор не принимает параметров.

## Поля класса 
`protected buyerData: IBuyer` - Хранит данные покупателя: способ оплаты, адрес, телефон и электронную почту.

### Методы класса 

`setField(field: keyof IBuyer, value: string): void` - Изменяет значение указанного поля данных покупателя.
`getBuyerData(): IBuyer` - Возвращает все сохранённые данные покупателя.
`clear(): void` - Очищает данные покупателя и возвращает модель к начальному состоянию.
`validate(): Partial<Record<keyof IBuyer, string>>` — проверяет данные покупателя и возвращает объект с ошибками валидации. Если поле заполнено некорректно, в объекте указывается соответствующее поле и текст ошибки.

### 4.Класс LarekApi
Класс отвечает за выполнение запросов к серверу интернет-магазина.

# Конструктор 
`constructor(api: IApi)` - Принимает объект, реализующий интерфейс IApi.

## Поля класса 
`protected _api: IApi` - Хранит экземпляр API-клиента, используемый для выполнения запросов.

### Методы класса 
`getProducts(): Promise<IProductResponse>` - выполняет GET-запрос на эндпоинт `/product/` и возвращает объект с массивом товаров.
`postOrder(order: IOrderRequest): Promise<IOrderResult>` - выполняет POST-запрос на эндпоинт `/order/`, передаёт данные заказа на сервер и возвращает результат оформления заказа.
